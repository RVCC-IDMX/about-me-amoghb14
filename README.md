**Description**
This project is an “about me” page, constructed to portray my biography, artwork, hobbies, and ultimately the web design expertise I have developed through *IDMX-225 Web Page Development I*. Through building this page, I have been able to expand on my preliminary understanding of programming with HTML and CSS, which I developed in middle school.

The project includes 8 main sections:

At the top of the page is a menu bar: Constructed with the *<nav>* tags.  While building the navigation bar, I learned to separate links to pages using *<li>* tags. The navigation bar allows the user to navigate to the Biography, Gallery, Blog, Contact form, and, of course, re-navigate back to the top of the site.

After that is the title section, which includes a logo and the title: “Web Page Dev I.” Added images to web pages using *<img>* tag. Used the paragraph tags to add name and location.

Below the title is a new section dedicated to a brief overview of myself with an avatar. I used the same expertise to embed an image in this section as well. The color choice in this section is different from that of the first section (a lighter green & darker border). This design is alternated with the bolder green with red border design section by section.

The next section is a gallery with pictures outlining my hiking, painting and space hobbies. Each image is accompanied by its respective caption.

Below the gallery is the blog section. I have included two blogs about hover effects and properties of backgrounds with examples for both. The sources used to research and create the embedded examples is listed below:
**hover effects:**
1.https://prismic.io/blog/css-hover-effects
2.http://www.codeitpretty.com/2013/06/how-to-use-css-hover-effects.html
3.https://www.emailonacid.com/blog/article/email-development/css-hover-effects-and-rollovers/
**properties of backgrounds:**
1.https://www.w3schools.com/cssref/pr_background-image.php
2.https://uploadcare.com/blog/css-background-image-how-to-add-it/
3.https://sbx.webflow.io/image-or-background-image

Below the blog is the embedded YouTube video, which was included using the *<iframe>* tag. I learned the true use of the embed link after seeing it while browsing through YouTube in my leisure time.

The final section is the contact form. I have previously implemented inputs into my own projects. But here, I learned how to integrate the form with Netlify so that the site actually stores responses.

**Color Scheme**
The color scheme is mostly shades of green and reddish-orange.
The color choices alternate with each section. The nav bar uses a gray and white color scheme for easy readability.
The sections then alternate between two schemes. One with a red border(#ff553b) and a dark green background(#1f3734), and another scheme with a background color that is lighter (#3D5761)and a border of #223035.

**NAVBAR**
The navbar links the site to the home, bio, gallery, and blog pages. The navbar is in the hamburger style with the three dots and the menu is collapsable for mobile users.
